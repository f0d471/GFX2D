x = src×Fs + dst×Fd　→　t = x + 128　→　out = min(255, (t + (t >> 8)) >> 8)
Fs、Fd 为 255 满量程整数；快速舍入式与 half-up 精确商全定义域逐值一致
六种方程共用同一条通路（每通道系数，255 满量程）
COPY　255, 0　——　不透明块
ALPHA　255, 255−a　——　预乘半透明
STRAIGHT　a, 255−a　——　赛题原式
ADD　255, 255　——　发光叠加
CONST　c, 255−c　——　整屏淡入淡出
MUL　dst, 0　——　阴影暗化
主路径预乘 ALPHA 每通道仅 1 次乘法；STRAIGHT 以直通 ARGB 源直接实现 fg×a + bg×(1−a)。
