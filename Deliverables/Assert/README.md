## 画图约定

**结构图用 HTML + SVG 绘制。** 底色 `#FAFAF7` 与幻灯片一致，线型和颜色各承载一种含义，已上板的部分画实线，
还没做的部分画灰色虚线。仓库里 `../../Engineering/TechReports/platform/fig/` 已有三张系统架构图，
可以直接作为幻灯片结构图的起点。

**颜色表示元素的种类**，同一种元素在所有图里用同一个颜色：

| 颜色 | 值 | 表示 |
| --- | --- | --- |
| 蓝 | `#4A7FD0` | 数据通路：总线、DDR3、HDMI，箭头也用蓝 |
| 红 | `#E8546B` | 控制与发起者：CPU、寄存器、状态机 |
| 绿 | `#67BA4A` | 计算单元：像素流水线、乘法器 |
| 金 | `#A37A1C` | 缓冲与存储：FIFO、片上缓存、帧缓冲 |
| 灰 | `#87929E` | 未实现的部分、对照组 |

图里画的是先后顺序或递进时（启动步骤、流水线各级），改用一条蓝色色阶，由浅到深：
`#7492AE`、`#5A7C9C`、`#3F668B`、`#174A7E`、`#0C2E4E`。

数据图里，蓝色是本设计，灰色是对照组。

**其他要求**

- 图里的标题不重复页面标题，图里不放注释段落。
- 中文字号在幻灯片上不小于 14pt 等效大小。
- 导出后检查文字有没有重叠、有没有被裁掉。
