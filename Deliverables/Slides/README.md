## 重新生成

内容页的图来自 [`../Assert/figures/report/`](../Assert/figures/report/)（2 倍像素导出）、
游戏画面来自 [`../Assert/measurements/`](../Assert/measurements/) 与 [`../Assert/photos/`](../Assert/photos/)。
改图后 PPTX 与 PDF 都要重新生成：

```
npm i pptxgenjs                                  在任意临时目录装一次，不入库
NODE_PATH=<临时目录>/node_modules node build_pptx.js
soffice --headless --convert-to pdf --outdir . gfx2d项目讲解.pptx
```

PDF 文件名改为带导出日期（`gfx2d项目讲解-<日期>.pdf`），新文件替换旧文件。
讲稿不入库；如需演讲者备注，在脚本各页 `addNotes` 后再生成，入库版本不带。
