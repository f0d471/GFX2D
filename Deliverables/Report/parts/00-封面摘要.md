#TITLE|GFX2D：基于 RISC-V 与 FPGA 异构架构的 2D 图形渲染加速引擎

#ABSTRACT
本作品面向嵌入式 2D 图形应用，在 Ti60F225 FPGA 上设计并实现了 2D 图形渲染加速系统 GFX2D。硬件部分为自研 BitBlt 渲染引擎，承担命令解析、图像块拷贝、纯色填充、Alpha 混合与色键去背，其中 Alpha 混合由 12 个 DSP 混合核承担，引擎作为 AXI4 主机直接访问 DDR3 显存，扫描输出经 HDMI（TMDS）以 640×480@60 Hz 显示；软件部分运行于易灵思官方的 Sapphire RISC-V 软核 SoC，包括 C 驱动、与硬件同规格的软件执行器和自研弹幕射击游戏 MYRIAD，逐帧发布 32 字节渲染命令驱动引擎执行。直通、条带、硬件分桶三种执行模式在同一比特流上切换，共用一套命令语义与像素流水线。上述设计经板上实测验证，同一命令表下硬件后端稳定 60 FPS、纯软件 2.5 FPS，加速约 24 倍；在开启 Alpha 混合与色键的条件下，以真实游戏负载自动搜索测得稳定 60 FPS 的同屏精灵极限 N_max 为 2187 颗（8×8 精灵），以 3600 场逐场零掉帧确认；参数缓冲后端同轮对照再提高 12.3%，每帧读突发减少 70%、写突发减少 92%；混合方程舍入经 8,421,376 组穷举一致，板上 9,208 帧逐帧一致；整机占用 60064 个 XLR（98.8%）、172 块片上 RAM（67.2%）、23 个 DSP（14.4%），核心时钟 setup/hold 余量 +0.104/+0.022 ns，无时序违例。%%系统完整实现赛题 7 项基础要求与 3 项高阶要求（见表 1），并给出五项创新功能（见 1.4 节）。%%
#END
