#TITLE|GFX2D：基于 RISC-V 与 FPGA 异构架构的 2D 图形渲染加速引擎

#ABSTRACT
本作品在 Ti60F225 开发板上自研了由 RISC-V 软核调用的 2D 硬件绘图引擎，并配套 C 驱动、软件渲染器和可扩展的游戏机前端，画面经 HDMI 实时输出，构成图形加速系统 GFX2D。处理器每帧更新状态并提交绘图命令，硬件完成图像块拷贝、纯色填充、Alpha 半透明混合与色键去背，结果写入 DDR3 帧缓冲；显示链路经双缓冲输出 640×480@60 Hz 画面。普通游戏短测从纯软件的 2.5 FPS 提升到硬件的 60 FPS，约 24 倍。常见 2D 加速引擎逐块直写帧缓冲，同屏活动元素（Sprite）增多，帧率随之下降；赛题要求开启混合与色键后保持 60 FPS，真正的考验是同屏活动元素的数量极限。为此引擎借鉴主流 GPU 的纹理缓存与分块渲染，形成三项创新：高频素材预先装入片上纹理，绘制时不再读 DDR3；条带缓冲把同一区域内的多次像素合成留在片上再写回帧缓冲，代价是 CPU 要替每个条带挑出 Sprite 各存一份命令；硬件分桶把这步交给 FPGA，只存 8 字节引用，不再复制命令。同一比特流、同一程序对照中，8×8 Sprite 的稳定 60 FPS 极限 N_max 从 1947 提升到 2187，增幅 12.3%；每帧 DDR3 读、写突发分别减少约 70% 和 92%。条带缓冲模式进一步扩展到三维：增加硬件三角形光栅与深度缓冲，板上实时运行可交互的三维走廊轨道射击（透视门框、敌机与弹幕），连续 1800 帧保持 30 FPS。整机占用 60,064 XLR、172 块 RAM、23 个 DSP。%%系统完成赛题 3 项基础要求与 3 项高阶要求，片上纹理、条带缓冲、硬件分桶与三维扩展构成四项创新成果。%%
#END
