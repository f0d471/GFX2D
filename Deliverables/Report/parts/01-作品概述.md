# 第一部分　作品概述

## 1.1 功能与特性

本作品是一套完整的 2D 渲染加速系统，包含硬件渲染引擎、显示输出链路、板上软件平台和一个真实可玩的弹幕射击游戏。

每帧的渲染流程为：RISC-V 处理器运行游戏逻辑，把绘制需求编码为 32 字节渲染命令写入 DDR3 命令表，写 DOORBELL 触发引擎取指；引擎以每周期 4 像素的吞吐完成像素搬运、Alpha 混合与色键去背，结果写入帧缓冲；扫描输出按场同步取数，经双缓冲与 TMDS 编码后以 HDMI 输出画面。

引擎保留直通、条带与硬件分桶三种执行模式，可在同一比特流上运行时切换：直通以 16 KiB 片上纹理承接高频小素材的读，条带以片上行缓冲把弹幕的随机写合并为条带连续写，硬件分桶把命令整理与分桶计算搬进硬件，CPU 每帧只发布一份原始绘制清单，各条带的紧凑引用表（参数缓冲）由引擎生成，跨条带 Sprite 不再复制命令。

三个演示模式覆盖赛题全部要求：基础演示（方块运动与大图切换，屏幕同屏显示软/硬件两路帧率）、可玩游戏（默认开启 Alpha 混合与色键）、压力测试（自动搜索稳定 60 FPS 下的同屏 Sprite 数量极限）。

## 1.2 应用领域

本系统面向以图层合成为主的 2D 嵌入式图形场景：仪表与设备的图形界面、图标与半透明面板的叠加显示，以及 Sprite 类 2D 游戏。这些场景由块拷贝、纯色填充、Alpha 混合与色键等基本操作构成，不需要 3D 变换与抗锯齿。渲染引擎的命令接口带版本号与能力寄存器，混合方程以表格方式扩展；引擎对外仅暴露寄存器与命令表两类接口，也可作为图形子系统集成进更大的 SoC 方案。

## 1.3 主要技术特点

本作品的技术特点体现在三方面。其一，全链路自研：除厂商提供的 SoC 软核、SDK 生成物与开发工具外，渲染引擎、显示链路、C 驱动、软件执行器、游戏与素材工具链均为自行设计，各层接口契约清晰，问题可定位到任意一层。其二，可观测与可对账：引擎内建九个性能计数器并附带恒等约束（如读 beat 数等于各读突发长度之和），帧率以场数减切换数客观定义，错误可定位到具体命令的字段，性能结论均绑定串口日志与产物指纹，可回溯到具体版本。其三，软硬同规格双实现：软件执行器与硬件流水线实现同一份逐像素规格，互为差分测试的对照，混合方程穷举校验与万张级命令表差分因此成为常规回归手段。

## 1.5 主要创新点

（1）硬件分桶渲染：分桶计算与跨条带命令复制移入引擎，N_max 同板同程序对照提升 12.3%（2.2.5 节）。

（2）片上纹理：16 KiB 片上存储承接高频小素材，其 DDR3 读事务降为零（2.2.5 节）。

（3）条带缓冲：弹幕的随机小写合并为条带连续写（2.2.5 节）。

（4）命令 ABI 与十步错误模型：错误可定位到具体命令与字段（2.2.4 节）。

（5）以实测反推架构：先实测控制器事务模型，数据布局与访存形态据此而定（2.2.2 节）。

## 1.6 设计流程

设计遵循实测先行、判据闭环的流程：开工前以探针主机实测 DDR3 控制器事务模型与多路器仲裁行为，确定访存形态与端口分配；随后划定存储地图与像素格式，完成引擎微架构设计与 RTL 实现；软件执行器与硬件同步开发，作为金标准支撑逐层对账；最后经综合时序收敛、比特流上板，以自动 N_max 搜索与 3600 场零掉帧确认收口。条带与分桶两种执行模式按同一流程递进叠加。

## 1.7 相关工作与本作品的定位

2D 图形的硬件加速有两条主线。第一条是合成语义：Porter 与 Duff 把 Alpha 合成抽象为一组算子 [8]，此后硬件混合单元的语义基本建立在这套代数上，本作品的六种混合方程与预乘主路径正是它的直接实现。第二条是固定功能 2D 引擎：面向 MCU 的 DMA2D 类加速器以寄存器级命令完成块拷贝、格式转换与两图层混合 [10]；FPGA 上也有面向 Sprite 的专用引擎，例如用高层次综合与片上存储实现多 Sprite 处理的硬件引擎 [13]，以及 2D 图形系统的软硬协同设计 [14]。这类工作把逐像素搬运与混合从处理器移入硬件，命令通常由处理器逐条写入、执行模式单一。

当像素通路不再是最紧的瓶颈，限制随之转移到访存。Rixner 等人的访存调度研究表明，行缓冲命中与突发组织对有效带宽的影响可以超过峰值带宽本身 [12]；Molnar 等人的排序分类则指出，按空间局部性重排访问可以把随机访问转成连续访问 [11]，移动端的图块化渲染沿用了同一思路 [16]。1.5 节前三项创新点正是把这两条结论落到 2D 弹幕负载上的结果。

与上述工作相比，本作品的定位在三点：命令以 32 字节定长表提交、由引擎自取，业界引擎的命令通常由处理器逐条写入；同一比特流上提供直通、条带与硬件分桶三种执行模式，可按负载切换并同板对照，业界引擎执行模式单一；为读、写、构造三个方向各建一级片上缓冲（16 KiB 片上纹理、640×16 行条带缓冲与参数缓冲），传统 2D 引擎没有这一存储层级。
