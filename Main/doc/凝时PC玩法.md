# 凝时 HALTTIME：PC与B7试玩

原生 Windows 入口为 `sw/apps/console/build_windows_sh_endless/gfx2dGame.exe --app sh`，
运行目录使用该 EXE 所在目录。通过 `tools/board/build_pc.py --out
Main/sw/apps/console/build_windows_sh_endless` 从仓库根构建。
控制台菜单按 **6** 进入；稳定目录 ID 为 **7**，ID6 是系统信息。
数字快捷键、目录 ID 和 R4 内部场景3分别是不同字段。

Windows在游戏窗口有焦点时读取原生物理按键，中文输入法下也可直接使用WASD；
窗口失焦时输入释放。无需切换系统输入法。

| 操作 | 键位 |
| --- | --- |
| 前后移动、横移 | W/S、A/D |
| 瞄准 | 鼠标；左右方向键也能转身 |
| 持续射击 | 按住鼠标左键或 Space |
| 拾取附近敌人掉落的枪，补至6发 | E |
| 手动装填 | R；弹匣打空会自动装填 |
| 释放鼠标 / 再捕获 | 右键 / 左键 |
| 回菜单 | Esc |
| 全屏 | F11 或 Alt+Enter |

停下时世界时间逐渐降到约0.025倍；移动、转动视角和成功击发使世界加速。
枪弹、敌人和碎片都随世界时间运动，玩家移动采用固定30Hz真实时间步长。
子弹飞行需要时间，射出后停住也会减慢自己的弹丸；观察轨迹并用横移避弹。
立柱可以遮挡视线和子弹，沙发、茶几按其实际高度参与碰撞。
默认是无敌无限模式：中弹或贴近敌人不会死亡，也不锁住移动或视角。
最多3敌同时在场；击杀后按真实时间自动补员，静止也不会卡在空场，
刷怪会避开玩家、家具和其他敌人，并在入口被占用时尝试其他入口。
击杀敌人留下可拾取的枪。每个弹匣6发，自动/手动装填约0.9秒，不需要重开或切关。

画面沿用项目的定点三维光栅路径与128字节记录。人物采用预生成的连续切面网格，
134顶点/228三角形、33个步态姿态；肩胸腰、头和肢体保持明确轮廓。
预计算面法线、逐面明暗与晶体亮面形成红色材质；第一人称枪和手同样使用三维切面网格。
PC版凝时使用独立2048条宿主记录缓冲；B7主表为256KiB/2048条，分桶128KiB，
深度条带32KiB，武器分桶另占64KiB。记录缓存从共享池offset 1MiB起租用1MiB，
世界中间表面占offset 2MiB起的2MiB窗口，均在2D arena之前，退出后归还。
静态环境、未变化的人形和武器姿态复用相同记录；缓存失效会重新计算，不复用旧视角。
近景与远景使用一致的切面造型，不在靠近时恢复密集曲面。单色三角形采用精确setup快路径，
深度梯度和128字节记录与通用路径逐字节一致；裁剪等情况仍使用通用路径。

PC叠加层显示准星、弹药、时间条、击杀与无敌状态。B7通过现有硬件2D条带阶段绘制
这些状态和准星，软件参考执行同一组命令。B7逻辑按实际经过的时间保持30Hz固定步长，
渲染慢时进行有界补步，装填与移动不会按绘制帧数变慢。

板端按6进入凝时，方向键/转发WASD为前后移动与左右转身，Space射击，Esc回菜单；
目前15位串口快照不包含PC横移/拾取/手动装填专用高位，板端仍可自动装填。
鼠标位移尚未接入板端。稳定与连续输入场景的实际帧率分别测量，30Hz是目标而非默认已达。
PC/软件参考与B7硬件的第一人称枪均使用独立深度。B7先绘制世界到中间面，
再加载该面、清理深度并绘制三维枪/手与HUD；不改世界深度精度。
