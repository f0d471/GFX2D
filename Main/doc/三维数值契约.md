# 三维数值契约（setup ABI v1，128B）

CPU 从视空间接管三维管线：近/远面裁剪、投影、guard band、扇形拆分、setup、条带分桶。
`sw/lib/gfx/rast_setup.h` 定义字节接口，`rast_ref` 消费同一份记录；R2 硬件按本契约实现。
全部计算为整数，UV 为仿射插值；采样约定为本项目自定义，不宣称图形 API 兼容。

## 1 舍入与矩阵

正分母 d 下定义 `F(n,d)=floor(n/d)`、`R(n,d)=floor((n+floor(d/2))/d)`。
R 是最近舍入，恰好半值向正无穷，例如 R(-8,16)=0，R(-9,16)=-1。
C 实现用商与余数避免 `n+d/2` 溢出；除法与裁剪不依赖 C 的负数截零语义。
每个标注 R 的位置独立舍入，不允许合并成单次舍入。

| 运算 | 公式、单位与位宽 | 边界例子 |
| --- | --- | --- |
| Q16.16 乘 | `sat_s32(R(a*b,65536))`，乘积 s64 | -1×32768 raw -> 0 raw |
| Q16.16 除 | `sat_s32(R(a*65536*sign(b),abs(b)))`，48 步无符号长除 | b=0 时按 a 的符号饱和，0/0=0 |
| 倒数 | 1024 项 Q1.30 种子，归一化到 [1,2)，一次 Newton 后按余数修正，结果与精确除法一致 | a=2 的倒数饱和到 INT32_MAX；a=0 返回 INT32_MAX |
| 矩阵 | 行主序、列向量；每个乘积先按乘法公式舍入/饱和，四项 s64 求和后饱和 s32；支持输入输出别名 | 单位阵保持任意 s32 分量 |
| 视口 | `x_raw=R((65536+x_ndc_raw)*640*8,65536)`；y 改成减号并用 480；输出 Q12.4 raw | NDC (0,0) -> raw (5120,3840)，即 (320,240) |

倒数表生成式 `seed[i]=floor(2^41/(2048+2i+1))`。归一化自变量 Q1.30，Newton
`y=floor(y*(2*2^30-floor(n*y/2^30))/2^30)`；缩放回倒数 raw 后按余数调整至正确
整数商，最后按符号做半值舍入。一次 Newton 对小除数不足以直接保证 raw 精度，余数校正
不可删。`gen_recip_tab.py` 检查入库表；算法自研，没有复制第三方实现。

投影为右手视空间，x 向右、y 向上、前方 z<0，near/far 为正距离：

```
q = cot(fov_y/2)
P = [ q/aspect  0  0                    0                 ]
    [ 0         q  0                    0                 ]
    [ 0         0 -(far+near)/(far-near) -2*far*near/(far-near) ]
    [ 0         0 -1                    0                 ]
```

系数逐项最近舍入到 Q16.16；q 使用现有 BAM 正弦表（最近 64 BAM）与精确定点除法。
fov_y 为 BAM，合法范围 [128,32768)，aspect>0、0<near<far，非法参数返回 -1。
投影后的 `z_ndc=(far+near)/(far-near)+2*far*near/((far-near)*z_view)`，
近面为 -1，远面为 +1。窗口深度 `clamp(R((z_ndc_raw+65536)*65535,131072),0,65535)`。
例如 near=1、far=9 时 m22=-81920、m23=-147456 raw，两个端点精确映射为 0/65535。
一般参数还包含矩阵系数量化误差，不宣称浮点管线逐位等同。

深度的 NDC 到窗口映射依据 [OpenGL 4.6 §13.8.1](https://registry.khronos.org/OpenGL/specs/gl/glspec46.core.pdf)；
矩阵量化、采样点和 UV 仿射均为本项目约定。

## 2 裁剪与 S3L 出口

S3L 默认 `S3L_F=512`，只输出视空间位置。转换为 Q16.16：`x=x_s3l*128`、
`y=y_s3l*128`、`z=-z_s3l*128`，s64 检查后写 s32，超域返回 -1。
如 S3L z=512，转换 z=-65536。自定义 S3L_F 时调用者先换回默认 512 单位。
不调用 `S3L_mapProjectionPlaneToScreen`，不复用它的近面策略；已有 cup3d 保持独立用途。

近面保留 `z<=-near`，远面保留 `z>=-far`，均在视空间、透视除法前用
Sutherland–Hodgman 裁剪。等于平面保留，避免近面重复裁剪抖动。顶点除位置外携带
u/v(u16 Q12.4) 与 ARGB8888，交点逐分量舍入，颜色按四个通道独立插值。

边 a->b 与第 k 分量等于 p 的平面相交时，对每个属性 t：

```
d = b[k]-a[k]
num = t_a*(b[k]-p) + t_b*(p-a[k])
t_new = R(num*sign(d),abs(d)); coordinate[k]=p
```

中间 num/d 用 s64，交点才舍入；权重式保证反向遍历同一条边得到完全相同的交点。
例如属性 0->3、权重 1/2 得 2，反向也得 2。每次裁剪后量化，下一平面使用量化结果。
透视除法逐坐标调用精确 Q16.16 div，然后视口映射，不从整数屏幕像素恢复亚像素。

屏幕凸多边形允许 3..8 个顶点；外部输入坐标范围为 raw [-2^28,2^28]。
饱和 Q16.16 NDC 映到 640×480 视口后，最大 raw 绝对值小于 2^28，不能在
guard 裁剪之前按 s16 或更小范围拒绝。按左、右、上、下顺序裁到：

- x_raw∈[-4096,14335]，即像素 x∈[-256,896)。
- y_raw∈[-4096,11775]，即像素 y∈[-256,736)。

上界以最大可表达 Q12.4 格点实现半开区间；不能裁到 896/736 后仍称半开区间。
之后以第一个顶点为锚按 (v0,vi,vi+1) 扇形拆分，最多 12 份记录；保持提交顺序。
空间裁剪也按上面的加权式插值全部属性。`stats.clipped` 统计 guard band 发生变化的
多边形，`backface/sliver/emitted` 统计拆分三角形；失败不提交统计或输出。

## 3 覆盖、边缘与包围盒

屏幕 x 向右、y 向下；像素 (i,j) 在 Q12.4 网格的 (16i,16j) 采样。
视觉顺时针提交：`area=(x1-x0)*(y2-y0)-(x2-x0)*(y1-y0)>0`；其余 CPU 剔除。
每条边 a->b：

```
dx=xb-xa; dy=yb-ya
A_px=-16*dy; B_px=16*dx; C0=dy*xa-dx*ya
E(i,j)=A_px*i+B_px*j+C0
top_or_left=(dy<0 || (dy==0 && dx>0))
bias=top_or_left ? 0 : -1
inside=(所有三条 E+bias>=0)
```

偏置由系数推导：A_px>0 或 A_px==0 且 B_px>0 时为 0，否则 -1。
例如三角形 (0,0),(4,0),(0,4) 拥有 x+y<4 的十个整点；其对角边 x+y=4
留给相邻三角形。水平上边和向上的左边拥有 E=0，下边和右边不拥有。
破平依据 [Direct3D top-left 规则](https://learn.microsoft.com/en-us/windows/win32/direct3d11/d3d10-graphics-programming-guide-rasterizer-stage-rules)，
本项目采样原点单独按整数点定义。

坐标跨度 dx≤18431、dy≤15871，故 |A_px|≤253936、|B_px|≤294896，均<2^19。
guard 矩形面积 18431*15871=292518401，保守上界 `18432*15872=292552704<2^29`；
三角面积绝对值不会超过该矩形面积。C0 的保守绝对上界
`15872*14336+18432*11776=444596224<2^29`。
帧内及循环末尾的边值保守界为 `444596224+253952*640+294912*480=748683264<2^30`。
因此边缘初值、步进、偏置全用 s32 安全；C 中间求系数用 s64，并拒绝越出 s32 的结果。
这里给的是可验证的保守界，不把近似指数当证明。

bbox 为 `xmin=ceil(min_x_raw/16)`、`xmax=floor(max_x_raw/16)`，y 同理；
先与帧 [0,639]×[0,479] 求交，记录存整数闭区间。负值例如 ceil(-17/16)=-1，
floor(-17/16)=-2。执行时再与 [16s,16s+15] 求交，空交跳过，记录与梯度不改写。
主表索引 u16，记录数≤65535。子表共 30 段，每段 `[u16 count,u16 0]+count*u16 index`，
无尾部补齐；空条带仍有 4B 表头，空帧为 120B。预先检查整表容量与记录再写出。

## 4 属性平面与像素提交

每个三角形所有属性从**顶点 0**的 Q12.4 (ox,oy) 出发，绝不是 bbox 原点。
基值转换：z0×65536，u0/v0×4096，RGB0 各通道×65536（均为属性 Q16.16）。
对基值 a0/a1/a2，CPU 发以下梯度，单位为“每整像素的属性 Q16.16 增量”：

```
Gx=R(16*((a1-a0)*(y2-y0)-(a2-a0)*(y1-y0)),area)
Gy=R(16*((x1-x0)*(a2-a0)-(x2-x0)*(a1-a0)),area)
acc(i,j)=a0+R(Gx*(16i-ox)+Gy*(16j-oy),16)
value=clamp(F(acc+32768,65536),0,limit)
```

初值 R(...,16) 后内环 +Gx，换行 +Gy；不重复除法。两级舍入不可合并。
任一 z/UV/RGB 梯度 |G|≥2^30 则整三角形 sliver 剔除并计数。
属性初值和累加器使用有符号 48 位（C int64）。帧内到原点距离总和小于 896+736 像素，
所以 `|acc|<65535*65536+1632*2^30+65536<2^41`，48 位足够。
原稿 s32 不能容纳 z0=65535 的 4294901760，已废除。

| 属性 | limit、单位与行为 | 边界例子 |
| --- | --- | --- |
| z | 65535；u16；严格 LESS，clear=65535 | z 相等不写，远面 65535 不写 clear 像素 |
| u/v | tex_width/height-1，texel 整数；nearest 后 CLAMP，纹理各边 1..4096 | u0 raw=16 -> texel 1；负值 -> 0；过界 -> size-1 |
| RGB | 255；逐通道，alpha 不参与合成 | -0.5 -> 0，255.5 -> 255 |

FLAGS.TEX_EN=0 时输出顶点色；VCOLOR_EN=0 等价白色。
TEX_EN=1 时最近采样原始 ARGB8888 texel，KEY_EN=1 且 texel 全 32 位等于 RAS_KEY 时，
色与 z 均不写。比较在调制前；TEX_EN=0 时忽略 KEY_EN。
否则 RGB 各自为 `floor((texel_channel*vcolor_channel+127)/255)`；无纹理直接用 RGB。
输出 XRGB8888，高八位恒 0。z 测试、色键、色与 z 的写入共同构成一次像素提交。
例如 128×255 -> 128，128×128 -> 64。纹理不存在、尺寸/stride 非法、保留位非 0 等
参数错误先整批拒绝，不能画一半后报错。stride 单位为元素，颜色/深度使用条带局部 y。

## 5 ABI 字节表

小端，主表 32B 对齐，128B 连续记录，允许跨 4KB；传输不使用 native struct 布局。
前 96B 偏移保留，后 32B 补齐原点与 RGB 梯度。保留位必须为 0。

| offset | bytes | 字段 | 格式 |
| ---: | ---: | --- | --- |
| 0 | 4 | FLAGS | bit0 TEX_EN，bit1 VCOLOR_EN，bit2 KEY_EN |
| 4/16/28 | 各 12 | E0/E1/E2 的 A_px/B_px/C0 | s32×3 |
| 40/42 | 2/2 | Z0 / reserved | u16 / 0 |
| 44/48 | 各 4 | DZDX/DZDY | s16.16 |
| 52/54 | 各 2 | U0/V0 | u16 Q12.4 |
| 56/60/64/68 | 各 4 | DUDX/DUDY/DVDX/DVDY | s16.16 |
| 72/74/76/78 | 各 2 | bbox X0/X1/Y0/Y1 | s16，帧坐标闭区间 |
| 80/84/88 | 各 4 | 原顶点 C0/C1/C2 | ARGB8888；基值取 C0 |
| 92 | 4 | reserved | 0 |
| 96/100/104/108/112/116 | 各 4 | DRDX/DRDY/DGDX/DGDY/DBDX/DBDY | s16.16 |
| 120/122 | 各 2 | origin X/Y | s16 Q12.4 |
| 124 | 4 | reserved | 0 |

头文件通过纯字节数组 layout proof 的每个 offsetof 与两个 sizeof 断言证明表格，64/32 位均编。
发送和接收只能走 offset 宏、小端 getter/setter；proof 类型不映射传输内存。

## 6 复现与交换向量

从仓根在开发环境配置的 WSL 中执行：

```sh
python3 Main/tools/check/validate.py --list
python3 Main/tools/check/validate.py --checks rast lib app workflow paths --profile acceptance
python3 Main/tools/check/validate.py --checks rast lib app workflow paths --profile acceptance --run
```

需按 [开发环境](开发环境.md) 配好 RISCV_BIN。`rast` 依赖 lib，正常 64/32 位库回归同轮去重；
专项另做 ASan/UBSan、三类定向变异、host.mk/target.mk 完整链接、宿主 rastTest 运行。
舍入检查包含分母 16/65536/255/65535/131072、完整窗口深度映射和 16 位可变正分母。
acceptance 为 100000 条光栅记录、10000 个几何三角形；quick 为 1000/100。
几何三方为 C setup、Python 整数、独立 Fraction 裁剪/重心梯度；光栅为 C 增量、
C 逐点直接求值、Python 逐点模型。固定 CRC 在 `sw/lib/test/rast_golden.txt`。
每个点均比较颜色和 z，CRC 包含记录、未写点和初始状态带来的结果，不能只比较覆盖数。

交换产物位于本轮 `logs/rast/`：`hand-vectors.json`、`geometry-vectors.json`、
`raster-vectors.json`、`summary.json`。记录为完整 128B 小端 hex，raster 向量给初始点、
纹理、色键与期望 color(u32)/z(u16) 小端字节流，R2 可直接转仿真 ROM。
固定种子与完整生成器可重建全部随机流。板上执行/硬件对拍由 R3 负责；R1 不产生性能结论。
