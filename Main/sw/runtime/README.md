# 通用应用生命周期

`include/appfw.h`只公开不透明user、生命周期和配置回调。配置提供应用表、菜单、
导航、能力、资源准备/恢复与遥测；管理器不包含游戏、R4、板级或引擎头。
一个固件有一个管理器所有者。稳定ID不依赖表顺序，重复ID拒绝初始化。

进入成功后才提交活动状态；失败后先撤销活动应用，再恢复物理资源、清理局部初始化，
然后进入菜单。恢复失败保持fault，返回动作可重试。应用离开必须确认排空。
框架不暴露帧缓冲序号、命令页、表面表或TEX状态。

`../ports/myriad/console_content.c`是现有内容的组合根示例；它包含游戏资源知识，
因此属于内容适配，不进入通用管理器。新平台消费者可直接使用`../api/`。
