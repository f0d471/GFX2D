# 平台与内容适配

`host/app_port.c`与`ti60/app_port.c`实现系统时间、输入快照、等待与任务状态。
Ti60采集/解码在临界区外，临界区只提交快照；health检查input/runner实际进展，
资源启动使用独立宽限，随后采用运行期限，按秒采样runner栈水位。

`myriad/`是已有内容的可信适配：资源/槽位/热集描述、2D和三维执行编排、背景pass、
统计与旧判据输出，以及现有console内容的生命周期接线。它允许认识游戏内容与
BSP/图形运行时；通用services和runtime不能反向包含本目录。
应用里的规则、场景、模型、素材与UI排版仍在apps，通用执行器在services/gfx。

公开SDK不依赖myriad。需要移植新内容时新增自己的适配器，不能修改公共BSP/库
以迎合每个游戏。旧判据通过本目录保留原CRC/录像与低层机制，不作为新SDK模板。
