## 当前规则

接口和运行方法见 `Main/sw/README.md`、`Main/doc/应用与输入契约.md`；验证范围以
`Main/doc/验证流程.md` 为准。软件执行器和三维参考模型是硬件判据的一部分。
共享区读回前须在外部写入完成后失效缓存；引擎完成与显示换帧确认分别决定资源何时可复用。
PC 耗时不作为板端性能，JTAG 不作为 Flash 启动证据。
