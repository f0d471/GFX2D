# platform 系列

在一块钛金 Ti60F225 开发板上搭出一条端到端可观测的硬件基线，供后面的 2D 渲染引擎挂靠。

平台为易灵思 Ti60F225（60K 逻辑单元，256 块片上 RAM，160 个 DSP），
板上有 256MB 的 16 位 DDR3、8MB SPI Flash、HDMI 发送口和一颗板载 FT4232H 下载器。
片内跑的是易灵思提供的 Sapphire SoC，核心是一个 VexRiscv RV32 处理器，主频 100MHz。

这个系列记录的是引擎之外的部分：工具链、下载链路、启动链路、顶层工程的组织方式，
以及每次改动之后要跑什么才算没退化。它不加速任何东西，收益全在后续工作的可观测性上。

## 实测结果

2026-09-16 的编译与上板：Efinity 2026.1 四步 PASS，用时 77 秒，
XLR 14517（23.9%）、片上 RAM 65 块（25.4%）、DSP 4 个，约束告警 0 条，无负 slack。
板上通过的判据有五项：JTAG 链路、memTest、HDMI 八色竖条、512KB bootloader 从 Flash 引导、
APB 探针寄存器读写。命令见 [`../../../Main/doc/开发环境.md`](../../../Main/doc/开发环境.md)，原始输出见本系列第 01 章。

## 这条线的当前位置

三条通路（下载、内存、显示）和两个接入点（程序空间、控制寄存器）都已经上板验证。
引擎本体、帧缓冲扫描输出、双缓冲都还没有开始，显示通路上跑的仍是硬件内部的彩条发生器。
