# engine 系列

渲染引擎本体与它访问 DDR3 的通路。引擎 P1 按层分六批（B1~B6），
路线、分层、层间接口契约与批次顺序见
[`../../Todo/hw/引擎P1总览.md`](../../Todo/hw/引擎P1总览.md)；
一批一章，章号与批号相同。

这一系列与其它系列的分工：

| 系列 | 覆盖 |
| --- | --- |
| [platform/](../platform/) | 工具链、下载链路、启动链路、顶层基线与回归判据、DDR 与总线的实测参数、多主机仲裁、扫描 FIFO |
| [spec/](../spec/) | 像素与命令的规格：方程、舍入、裁剪、色键、字节序、命令位域 |
| **engine/** | 渲染引擎本体：六层的实现、层间接口的时序、引擎侧的复测 |
| [display/](../display/) | 帧缓冲扫描输出、双缓冲与场同步 |
| [sw/](../sw/) | 驱动、PC 平台层、软件执行器、素材流水线、游戏、演示模式与统计 |

## 判据与工具

| 文件 | 用途 |
| --- | --- |
| `Main/rtl/engine/engine_blend.v` | B1 的混合核，一个文件一个模块，接口就是层间契约 I6 |
| `Main/sim/engine/blend/run.sh` | B1 的仿真：全定义域穷举、抽样金标准、停顿、五个注错 |
| `Main/rtl/engine/engine_mover.v` | B2 的搬运层，接口是层间契约 I2、I3、I4、I7 |
| `Main/sim/engine/mover/run.sh` | B2 的仿真：协议与上下文、复位与排空、错误、超时，五个注错，另加从机定时模式的回归（`tb_slave_timed.v`） |
| `Main/rtl/vendor/verilog-axi/` | B2 用的两个第三方 DMA 核与许可（MIT，源码一字不改） |
| `Main/sim/axi_probe/axi_ram_model.v` | 四个仿真共用的从机，B2 按 D13 补了 4 MiB、`wstrb`、按区间回 `SLVERR`、定时模式四样 |
| `Main/tools/check/check_subst.c` | 六个方程的代入表与逐位等价穷举（全定义域 50462976 组），另有 16 位截断注错与替代代入的等价性 |
| `Main/tools/check/check_round255.c` | 规格侧的舍入校验；`--golden <文件>` 可选模式导出 1024 条抽样金标准给仿真对账 |
