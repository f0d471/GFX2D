# blend 排版复核证据

过程、判据与结果见 [计算核心第 4.7 节](../../01-计算核心.md#47-2026-11-14-排版复核)。

| 入口 | 范围 |
| --- | --- |
| `static-review.json` | 与 `12db1db2` 对比，680 个 Verilog 词法单元相同；保留两份文件的 SHA256 |
| `rtl/` | quick 的 blend、pix、frame 与五条 blend 外部变异；包含普通基线、具体检查器、原始输出及输入身份 |
| `rtl/logs/blend/` | 16 份本轮新生成的规格侧/正常用例原始日志，复制时核对时间与 SHA256 |
| `synthesis/` | B0 当前源码独立生成树的真实四步、资源、全部时钟 setup/hold、告警和网表检查 |

另对全部 79 条变异规则执行只读 `--audit` 并通过；本轮实际执行的变异仅为五条 blend，
不以全仓规则审查代替全仓变异运行。quick 不表示全仓验收；本轮没有部署板卡、写 Flash 或替换冻结快照。

`archive.json` 和 `archive-files.json` 登记归档方式与逐文件摘要，原始日志不覆盖。
