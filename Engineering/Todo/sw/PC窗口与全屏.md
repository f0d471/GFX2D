# PC窗口与全屏

状态：**待验收，已实现并通过原生Windows窗口验收和运行包实测**（2026-10-24）。

## 1 要解决什么

用户检阅 PC 游戏时提出无法全屏。当前 `Main/sw/bsp/host/board.c` 创建固定大小的
SDL2 窗口，只有 F1/F2/F3 的 1x/2x/3x 缩放，没有全屏切换，也没有保持比例的任意窗口缩放。
这属于 PC 显示层的待补功能。全屏只改变显示方式，不自动提高 640x480 帧缓冲的细节。

## 2 实现范围

1. F11/Alt+Enter切桌面全屏，Esc退回窗口，恢复原尺寸/位置。
2. 全屏/窗口缩放保持整帧 4:3，居中留黑边；不把现有 400x480 世界与右侧 HUD 拉宽。
3. 提供最近邻/平滑放大选择。平滑放大属于 PC 呈现处理，不登记为三维抗锯齿或板上画质提升。
4. 处理 Windows DPI、跨显示器、失焦/重新聚焦，以及 SDL 纹理重置；保留 F1/F2/F3 的既有入口。

实现集中在 host BSP 和必要的启动/构建入口；原生 Windows 与 WSL SDL 的支持范围下一轮确定。
不以改游戏按键位图或回放格式实现全屏。

## 3 判据

- 进入/退出全屏、恢复位置与比例正确，HUD 不变形；重复切换、Alt+Tab、关窗和输入释放正常。
- 缩放不改变游戏逻辑、640x480 帧缓冲内容、录像输入与原始截图身份。
- `SDL_VIDEODRIVER=dummy` 的既有用途不受影响；按 host BSP 的消费者选择应用/PC 显示验证。
- 本功能不改变板端显示路径；若后续扩大范围，按实际依赖重新登记判据。
