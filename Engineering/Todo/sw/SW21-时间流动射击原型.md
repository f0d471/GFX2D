# SW21 时间流动射击(工作名「凝时」,Superhot-like)

状态:进行中——SH2 PC无敌无限版、连续人形材质与贴墙武器修复的所选acceptance通过，
新版原生PC已打开，待用户试玩；SH3板端验收未开工，阻塞见 §2 前置。不阻塞其他在册条目。
不动 RTL；独立 sh 应用用快捷键6进入，稳定目录 ID7、内部场景3。

## 1 要解决什么

赛后给作品新增一条全 3D 通路的游戏模式候选:借鉴 SUPERHOT(2016,Superhot Team)
的「时间随你的动作流动」机制,做白色房间+红色敌人+黑色枪的纯色射击模式。
机制本身不受版权保护,可借鉴;原名、原素材、原代码一律不碰(商业闭源,本无移植可能),
借鉴边界见 §5。

选它的理由(2026-11-04 调研+对齐结论):

- 纯色平涂是该玩法的**原生画风**:无纹理、无阴影、无渐变,恰是 R4 栈最便宜的 L1 档;
  「像多边形 Unity」的观感在评审语境里是加分项。
- 世界空间弹幕 billboard(R4 已落地)静止即「悬停弹」,零新渲染机制。
- 时间冻结天然掩盖帧率波动——不动时画面是静帧,恰好绕开我们的帧时间短板。
- 给「3D=条带模式推广」补一个非弹幕轨道的第二场景形态,演示覆盖面 +1。

## 3 判据

SH1(本步,2026-11-04):

- 单文件 HTML,无外部依赖,离线可开;URL hash 预置状态(`#t=秒` 快进、`#demo`、`#shot`)。
- 画面为 L1 平涂语义:逐面单色填充,无纹理/阴影/渐变;亮度为**烘焙的每面常量**,
  不随帧变;HUD 走 2D 层语义(文字/矩形,不计三角形)。
- 实时三角形计数显示且 ≤1870(R3 N_max 记录);超限变红(设计上不应发生,发生即预算设计错)。
- 时间机制可感知:静止时世界近停(下限 0.05),移动/开枪升至 1.0;玩家自身不随缩放;
  中弹后时间强制回 1(SUPERHOT 的「死时时间飞逝」)。
- Edge 无头截图三状态(凝滞/交火/碎裂)目检通过,图与题注相符。

## 5 调研(2026-11-04)与预算

机制本质(来源全部只参照机制,不移植代码/素材):

- `worldDelta = dt × timeScale`;`timeScale` 向目标平滑收敛,下限 ~0.05 不为 0
  (凝滞时弹仍蠕行,画面不死),上限 1.0;目标 = 输入幅度的函数,输入幅度 =
  移动速度 + 视角转动量 + 开枪,合并归一。玩家自身走真实 dt——这就是「你动时间才动」。
- 参照物:[Mix and Jam Superhot-BulletTime](https://github.com/mixandjam/Superhot-BulletTime)
  (Unity 教学复刻,机制参数好对照)、three.js 展示页
  [SuperCool](https://discourse.threejs.org/t/supercool-a-simple-fps-game/15574)、
  网页可玩 [Time Shooter](https://www.funny-shooter2.net/game/time-shooter)(手感基准)、
  官方 SUPERHOT(VR 版按身体位移度量,键鼠版按合并输入,见
  [机制拆解](https://developers-codex.hashnode.dev/breaking-down-superhots-time-mechanic))。

与我们栈的逐项对齐(增量一栏「0」=已落地直接复用):

| 玩法要素 | 我们已有的对应 | 增量 |
| --- | --- | --- |
| 白色房间平涂 | L1 RAST,逐面 RGB(R1 记录原生) | 0 |
| 红色低多边形敌人 | R4 自机同款盒子人(每面一亮度) | 0 |
| 悬停弹 | 世界空间 billboard(R4 敌弹同机制,静止即成) | 0 |
| 击碎成红多边形 | 弹幕池改造:shard=单三角形,每片 1 条 | 弹幕池 |
| 黑色枪(第一人称) | 相机系常驻几何,离相机极近 | ~16 条 |
| 时间缩放 | 纯 CPU,world_tick 乘因子 | 0(逻辑层) |
| 一击死/波次 | 纯逻辑 | 0 |

预算(目标 ≤1870,SH1 页面实测):房间壳 ~174、敌人 4×72=288、弹 128、
碎裂 3×20=60、枪 16、描边(可选)~120 → 峰值 ~700,余量 >1000。

## 6 风险

- **CPU setup 吞吐是 SH2 的头号工程问题**:R4 走廊靠 120 相位预热缓存
  (`r4_world_prewarm`)把 view→setup 摊薄;SH 自由视角+任意位置无周期性,缓存不可用。
  总览 §6 的 1100 条/504ms 探针是含属性梯度的口径;L1 平涂只剩边缘函数+z 梯度
  (无逐属性除法),理论成本大幅低于该数,但**必须先实测**,以实测决定:
  三角形上限、是否 30Hz 发射双场复用(SW19 先例)、是否视角量化缓存。
- 帧率:走廊退化查明前,SH 场景不引入任何逐顶点光照路径(11-01 退化嫌疑),
  每面恒定色烘焙。
- 填充率:白墙大三角形满屏 3~4ms/面量级,房间小物体少,重叠可控;波次上限
  同屏敌人 ≤4 是填充与 setup 双重预算。
- 2026-11-05(SH2 首启画面损坏返工,四连修):用户截图暴露整幅画面结构性损坏
  (70% 背景色+几何拉丝)。逐面仪表(host-only fprintf,已拆)定位出四个叠加根因,
