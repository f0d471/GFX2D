# 绘制前端 F1 成本分解与基线

状态：**待验收**。前置：P3/G4 已验收。阻塞 F2/F3 的采用及 F4/F5 的收益预算。
共同契约与最终门槛见 [总览](绘制前端总览.md)；本批只增加计量与研究探针。

决策依据：engine 第 11 章 D64、D66、D75、D76；成本口径与缓存因果分开验证。

## 1 要解决什么

已有日志只分 logic/build/exec，缺少固定绘制、裁剪、源检查、复制与 DDR 写入的
受控分段。观测拟合给出 build≈0.93M+635×敌弹，但不能判定哪段值得下沉。
同样不能把 16KB 候选的整体收益单独归因于桶散写。

## 2 怎么切分

### 2.1 固定输入与测量单位

增加 `sw/apps/probe/frontendBench`，公共输入与运行循环放在 `lib/gfx` 的独立
研究入口或 `sim/engine/frontend` 的宿主夹具；被测构造调用真实生产函数。
不另造省略校验的快循环冒充当前构造。

输入包含两型固定 K=0/384/1024/1648/1984/2400，以及完整回放中的首帧、Boss、
第 9000 帧和通关前后；每帧保存表面、clip、绘制状态和坐标。跨方案复用完全相同
的输入文件；输出由计时外独立编译单元读取，不启用跨单元 LTO。额外测非游戏矩形：
1×1、7×31、16×16、20×20、6×24、640×480，变化源坐标、stride 和方程。

分别记录每帧、每逻辑实例、每输出片段、每输出字节的成本，禁止混用 K 与可见数。

### 2.2 分段与受控矩阵

| 组 | 被测工作 | 输出消费者与对照 |
| --- | --- | --- |
| A | 原生产直通构造 | 原 v1 字节与记账，TEX 直通 CPU 基线 |
| B | 原 v2 全流程 | 原条带字节、计数、首错；保持原参数校验和原子性 |
| C | 单独列出背景、HUD、其它固定绘制 | 原序列阶段边界；不从测量中删掉实际工作 |
| D | 参数/共同字段检查、全局裁剪、容量预检、片段生成、输出存储 | 原子操作外层粗粒度打点，细分批量打点；减去空探针成本 |
| E | 同一合法 32 B 记录流的顺序/桶顺序/当前散写 | 同地址集合、同数据、同预热、同存储次数；计时外全字节比较 |
| F | F2/F3 的预算探针 | 同一场景的 prepass/计划/引用/完整输出，全段求和并列依赖 |

4KB 是主测。16KB 仅复用候选 bit 做同一 BIN 对照，记录容量与路数共同变化。
缓存机制实验增加读/写分离、相同组/不同组地址、冷/热对照；不得重排生产 v2 的
32 KiB ABI 桶基址。检查反汇编存储确实存在，并核对写穿透、不写分配的生成逻辑。

主微基准先关闭渲染以隔离 CPU，随后同一输入在真实扫描＋引擎争用下再测；两组
分开登记。ASan 与像素校验单独运行，不夹在目标计时里；所有候选采用相同的校验后
预热规则。板上计时使用 `board_cycles`，保留 CPU 100MHz 与实际帧场计数。

### 2.3 输出与预算决策

每组至少 1000 帧、三次独立重复；记录每次总周期、p50/p99/max、实际输入实例数、
输出记录数、字节数、错误数、补入/状态摘要。对高开销逐颗打点另测探针干扰，不将
累加的细项当未经校准的帧时间。分段和总计差额单独记 residual，不强行对齐。

建立相同 N 下的 CPU/GPU 依赖图，以及 K=目标负载的预算表。
对 F2 必须填 `C_prepass`、额外写/读字节与状态更新；对 F3 填 plan/ref 额外流量；
对 F4 填实例打包、DMA 和展开；对 F5 填两次坐标遍历、metadata/ref 写与执行再取数。
未知项以区间和待测项列出；没有足够数据的候选不进入“预计可达到某 N_max”的表。

### 2.4 文件与接线

| 位置 | 动作 |
| --- | --- |
| `Main/sw/apps/probe/frontendBench/` | 板上固定输入、打点、输出消费与自检 |
| `Main/sim/engine/frontend/` | 独立输入、期望输出、复现命令与研究结果 |
| `Main/tools/check/` | 采集日志的外部检查器；校验字段、完整性和重复性 |
| `Main/sw/apps/game/gfx2dGame/src/stg_modes.c` | 默认关闭的粗粒度阶段计量；原生产性能构建保持原口径 |
| TechReports engine 后续成本专题 | F1 实测与分析单独归档；第 11 章保持 D64～D76 的决策制定记录 |

## 3 判据

- A/B 与当前生产字节和错误记账一致；固定输入在宿主与 RV32 的输出一致。
- 数据均被消费；删除一个输出字段的写入必须被输出检查发现，关闭一次正确检查
  必须被反例识别；错列、重复/缺失组、溢出、未 done 的日志不得判通过。
- 每次记录完整矩阵及原值；三次差异 >2% 查明或明确登记未稳定，不只取最小值。
- 同一场景全段预算和实际帧计时对账，解释 residual；不将微基准的无争用数字
  直接作为整机收益。
- 输出 F2/F3/F4/F5 的启动预算与优先级，含允许失败的候选与停止条件。
  本批完成不宣称 N_max 已提高。
