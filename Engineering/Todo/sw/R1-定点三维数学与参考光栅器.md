# R1-定点三维数学、setup 与参考光栅器

状态:**待验收**（2026-10-22：实现、acceptance 五项及证据归档通过；128B ABI 与 golden 已冻结）。
总览见 [../hw/三维光栅总览.md](../hw/三维光栅总览.md)。

## 1 要解决什么

三维光栅先行需要三层软件基础,现有资产都不能直接替代:

- **像素级精确的数值契约与参考光栅器**。R2 的硬件光栅核按「软件执行器=金标准」方法学验收
  (doc/赛题二总体设计.md 3.8),必须先有一份与硬件位精确一致的 C 参考实现。small3dlib
  是软件渲染器但有自己的定点约定与质量取舍,不能当金标准。
- **CPU 侧几何与 setup 管线**。定案(2026-10-22 评审):**三角形 setup 由 CPU 完成**——
  属性梯度需要面积归一化(除法或倒数乘),硬件做就要定义多周期除法/倒数的算法、误差、延迟
  与资源,工期不允许;且同一三角形跨多条带时 CPU setup 只算一次。硬件只收 setup 参数
  (边缘系数/梯度/包围盒)并做增量扫描。RasterIX 软件侧同样预计算边缘方程与插值增量。
- **无 FPU 的 3D 数学**。CPU 是 rv32im(settings.json:65 FPU=0)。现有 fixmath 是 Q.8 游戏
  定点+三角函数,没有 Q16.16 矩阵/投影/除法。

## 2 怎么切分

### 2.1 数值契约（实现后复核定案）

当前唯一规格源移入 Main 自包含文档
[三维数值契约](../../../Main/doc/三维数值契约.md)，本条目保留开发过程。
2026-10-22 实现复核推翻原稿四处假设：

- u16 深度乘 65536 最大为 4294901760，不能用 s32 累加；z/UV/RGB 全部用有符号
  **48 位属性累加器**（C 用 int64），边缘函数仍为 s32。
- Q12.4 UV 转 Q16.16 乘 **4096**，原稿 `u0<<16` 多乘 16。
- 原稿没有属性插值的原点，也未给 RGB 梯度，无法实现硬件无除法的增量着色。
  ABI 扩为 **128B**，保留前 96B 的字段偏移，增加 RGB 梯度与顶点 0 屏幕原点。
- 固定视空间为右手系、前方 z<0；标准 OpenGL 投影近面 NDC=-1、远面=+1。
  原稿深度公式符号颠倒；规范公式、饱和与逐级舍入写入当前契约。

| 偏移 | 字节 | 字段 |
| ---: | ---: | --- |
| 0 | 4 | FLAGS：[0]TEX_EN [1]VCOLOR_EN [2]KEY_EN，其余 0 |
| 4/16/28 | 各 12 | 三条边 A_px/B_px/C0（s32，像素步长已含 ×16） |
| 40/42 | 2/2 | Z0(u16) / 保留 0 |
| 44 | 8 | DZDX/DZDY(s16.16) |

主表 32B 对齐，128B 连续存放，允许跨 4KB。逐字段 offset 宏、offsetof/sizeof

`[u16 count,u16 0]+u16 index[]`，共 30 条带，索引与提交顺序一致。
### 2.2 fixmath 扩展(sw/lib/core/fixmath.c/h)

- Q16.16:mul(`mul`+`mulh`)、div(长除)、recip(1024 项倒数表+牛顿一次修正+余数校正;
  libfixmath(MIT)只作算法参照);mat4×vec4、透视投影(near/far/fov 参数化)、
  视口变换(输出 Q12.4)。
- 与既有 Q.8/二进制角工具共存,前缀 `fx16_`,不改既有函数。

### 2.3 几何管线与 small3dlib 边界(出口前移)

- **S3L 只用到视图空间为止**:场景/模型数据、模型矩阵与视图变换。评审证实
  `S3L_mapProjectionPlaneToScreen`(small3dlib.h:1923)整数除法直出整数像素——**不经过它**,
  亚像素无从恢复;其近面策略(`S3L_NEAR_CROSS_STRATEGY` 默认 0)不做正确裁剪——**不用它**。
- 我方管线接管视图空间之后:近面 Sutherland–Hodgman 裁剪（视空间 z<=-near，含远面 z>=-far）→
  透视除法 → Q12.4 视口映射 → 屏幕 guard-band 裁剪(2.1)→ **setup**(按 2.1 产 128B 记录)
  → 条带子表分桶。全部定点,裁剪与除法的舍入式进 2.1 契约。
- 两套数学的关系:S3L 定点约定只存在于视图空间之前;`fx16_` 服务于我方管线;
  转换点唯一(视图空间出口),配边界值穷举小测试。

### 2.4 参考实现(sw/lib/gfx/rast_ref.c/h + rast_setup.c/h)

- `rast_setup`:几何管线尾段(2.3),输入屏幕空间多边形,输出 128B 记录+条带子表。
- `rast_ref`:按 2.1 契约逐像素实现(消费 setup 记录,与硬件同输入同输出);
  接口风格对齐命令层(条带局部 y)。PC 单测、板上对拍、R4 软件对照三种用法。
- 独立第二实现 `rast_ref2`(ref_exec 模式:不同代码组织,同一契约),三方对拍防规格误读。

### 2.5 向量与 fuzz(两层)

- **光栅层**:手算向量(平顶/平底/任意朝向、共享边不重不漏、跨条带、退化 area2=0、
  E=0 恰落在 top/left/right/bottom 四种边、guard band 边界 x∈[-256,896)、y∈[-256,736)、z 相等 LESS 不写、
  UV CLAMP 两端)+ xorshift32 定种子随机记录流 N≥10 万,三实现交叉。
- **几何层**:矩阵/投影/裁剪端到端向量(含近面跨越、guard band 恰触发、扇形拆分),
  对拍 rast_setup 输出的记录字段。
- golden CRC 入库 sw/lib/test/(对齐 golden.txt 模式),R2/R3 直接取用。

## 3 判据

1. 2.5 两层手算向量在三份实现(rast_ref/rast_ref2/穷举脚本)上逐位一致;每条向量注明
   钉住的契约条款;每条舍入式配 16 位域穷举脚本(check_round255 先例)。
2. fuzz:光栅层 N=100,000 记录、几何层 N=10,000 三角形,三实现 CRC 相同;
   至少三类注错见红(破平改非 top-left、A_px 漏 ×16、guard band 裁剪关掉后 s32 溢出可复现)。
3. `offsetof`/`sizeof` 静态断言(2.1 字节表)在 64 位与 -m32 下都过;S3L 出口边界测试过。
4. PC(host.mk)零告警;板上(target.mk)编过(板上运行归 R3)。
5. 契约文本(2.1)按评审意见二次复核一遍:公式、单位、位宽、边界例子四要素逐条齐全。
