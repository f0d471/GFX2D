# SW8 演示模式、压力测试与统计埋点

状态：未开工。前置 SW6、SW7。它产出的统计 CSV 是技术报告里计算类型统计的第一版实测数据（设计文档 4.5 节）。

## 1 要解决什么

设计文档 4.3 节要求三个演示模式一键切换：基础 Demo、游戏、压力测试。
压力测试按 0.2 节的口径求 `N_max`，是报告里最核心的一个数字。
4.5 节的计算类型统计现在全是按场景参数推算的，4.6 节要求软件执行器与硬件用同一套口径埋点，
这样软件与硬件、PC 与板子的数字才能逐项对照。

## 2 怎么切分

### 2.1 模式切换

数字键 1~3（板上用按键组合）切模式，切换时清空实体池、重置裁剪框与统计。
Tab 在软件执行器与硬件引擎之间切换（PC 上只有软件，记日志）。

### 2.2 压力测试

- 游戏场景去掉自机的受击，敌弹数从 N0 开始，每 2 秒加 ΔN，出现掉帧（`FRAME_DROP`）后回退，
  步长减半再逼近，直到步长小于设定值。设计文档 0.2 节的口径：开启 Alpha 与色键、稳定 60 FPS。
- N0、ΔN、最小步长、「稳定」要求的连续帧数都做成常量并在 CSV 头里输出。
- 结束后在 HUD 与串口给出 `N_max` 与当时各段耗时。
- PC 上跑出来的 `N_max` 没有意义（总览约束 5），PC 上只验证流程；数字在 SW9 板上出。

### 2.3 统计埋点

每秒一行 CSV，字段照设计文档 4.6 节：

```
t, mode, exec(sw|hw), fps, drop, n_bullet, cmd, pixel, key_skip,
cyc_logic, cyc_build, cyc_exec, cmd_by_eq[0..5], pixel_by_eq[0..5]
```

- 按方程分类的命令数与像素数由执行器统计给出，与 4.5 节的表逐行对应。
- `Main/tools/plot_stats.py`：读 CSV 画出每种运算的像素占比、帧时间分布，直接生成报告用图。

本条**不含**：板上的实测（SW9）、硬件计数器的读取（SW9 的驱动）。

## 3 判据

| 项 | 判据 |
| --- | --- |
| 切换 | 三种模式来回切 50 次，无泄漏（池计数回到 0）、无残留裁剪框 |
| 压力测试 | 在 PC 上人为给执行器加固定延时模拟慢速平台，`N_max` 随延时单调下降；流程能自动结束并输出结果 |
| 对账 | 每行 CSV 里 `pixel_by_eq` 之和等于 `pixel`，`cmd_by_eq` 之和等于 `cmd` |
| 第一版统计 | PC 上场景 S1 的按方程像素占比与设计文档 4.5 节的推算并列登记，差异逐项解释 |
| 画图 | `plot_stats.py` 对一份样例 CSV 出图；图的去处与格式按 [`Deliverables/README.md`](../../Deliverables/README.md) 的约定 |
