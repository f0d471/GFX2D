# SW5 素材流水线

状态：未开工。前置 SW1；素材包的大小上限等 [E6](E6-SPI装载速度.md)，先做成参数。
阻塞 SW6、SW7 的正式画面（之前用程序生成的占位图）。设计文档 6 节第 4 条要求在 M3 之前做完。

## 1 要解决什么

纹理要以**预乘 ARGB8888**存放（设计文档 3.5 节），板上启动时从 Flash 素材区（`0x400000` 起 4MB）
拷到 DDR 素材区（`0x0100_0000` 起 16MB）。PC 版从文件读同一个素材包。
没有这条流水线，游戏里的每张图都得手写成数组，改一张图要重编程序，而且预乘的量化偏差没有地方记录
（spec 第 01 章：预乘路径最大偏差 254/255，「偏差要在素材工具里记着」）。

## 2 怎么切分

### 2.1 工具：`Main/tools/pack_assets.py`

WSL 里的 python3 + Pillow（2026-09-19 已核对：python 3.14.4、Pillow 12.2.0）。

```
输入   assets/manifest.txt      每行：名字  PNG 路径  类型(sprite/atlas/bg/font)  [色键]  [切片网格]
输出   build/assets.pak         素材包
       build/assets.h           编号枚举 + 每项的宽高、图集内的子矩形表
```

- 预乘：`round(c × a / 255)`，舍入与 spec 第 01 章相同；统计每张图因预乘改变的像素数与最大偏差，打印到构建日志。
- 色键图：保持不透明，不预乘，色键值写进头文件。
- 图集：同尺寸小图按网格拼成一张，子矩形表进头文件，游戏只按编号引用。
- 背景：640 宽以上的图按设计文档 2.2 节的约束，拆成图块或整张存放，由 manifest 指定。

### 2.2 素材包格式

```
头       magic "G2DP"  版本  条目数  总长  整包 CRC32
目录     每项：编号  偏移  长度  宽  高  格式  CRC32
数据     每项按 64 字节对齐（一个缓存行）
```

解析与校验放 `sw/lib/core/assetpak`，PC 与板子共用。板上装载后逐项校验 CRC32，失败的项在串口报出编号，不静默使用。

### 2.3 Flash 镜像合成

`Main/tools/make_flash_image.py`：比特流 + 程序（`0x380000`）+ 素材包（`0x400000`），按设计文档 2.2 节的分区合成一个 hex。
素材包超过上限（参数，当前 4MB）时报错退出。

### 2.4 占位与正式素材

- 占位：`Main/assets/placeholder/` 下由脚本生成的纯色方块、圆形弹幕、渐变背景、棋盘格，许可无问题，先用它们把全流程跑通。
- 字库：8×16 点阵，95 个 ASCII 字形。选公有领域或 CC0 的字库，或自己画；入库前在 `Main/assets/LICENSES.md` 登记来源与许可。
- 正式素材：自己画或选 CC0 素材，同样登记。**没有登记许可的素材不入库**。

本条**不含**：8 位索引加调色板格式（本版不实现，设计文档 3.5 节）、RLE 压缩（素材超出 4MB 时再开条目）。

## 3 判据

| 项 | 判据 |
| --- | --- |
| 预乘 | 工具的预乘结果与 C 侧按 spec 第 01 章式子算的结果，对 256×256 组 `(c, a)` 全部一致 |
| 往返 | 占位素材打包再由 C 侧解包，逐项 CRC32 一致；注错：改包中一个字节，C 侧装载报出对应编号 |
| 大小检查 | 人为放一张超限的图，工具报错且退出码非 0 |
| 镜像 | 合成的 hex 在各分区起始地址处的内容与输入文件逐字节一致 |
| 许可 | `Main/assets/LICENSES.md` 覆盖 `Main/assets/` 下每个非生成文件 |
