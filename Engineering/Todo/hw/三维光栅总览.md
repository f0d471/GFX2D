# 三维光栅总览(R 系列)

状态:**拍板完成(2026-10-22),R 系列开工;同日完成一轮静态评审并修订全部 spec**。
本文件是三维光栅先行工作点的总览:拍板记录、技术选型与开源调研结论、R1~R5 清单、
阻塞关系与排期。未完成项的 spec 在各 R 条目里,已验收项的过程与数据归 TechReports
(engine 系列续章)。下节点:2026-11-04 18:00 作品提交。

## 1 背景与拍板记录

嵌赛全赛道统一评选,评委临时接题、非本赛题专家;赛题三优秀作品在演示效果与工作量观感上有
隐藏分。本工作点在不动 2D 主线任何已验收结论的前提下,给作品增加一条 **3D 固定管线**
(总纲 4.6 G3 的嵌赛先行)与 3D 演示模式。硬约束:2D 报告数字、验收证据与可复现性一分
不能丢;3D 全部走增量(新机制宏 + 新预设),任何时点可放弃、回退无损。

2026-10-22 拍板,四项全按调研建议:

| 项 | 定案 |
| --- | --- |
| 做不做 | 做,按降级阶梯 L1(平涂)→L2(TEX 纹理,主目标)走 |
| 基座预设 | **B3**(条带+TEX+INST;归档综合 **43816 XLR/165 RAM/19 DSP**,见 engine 第 15 章);B5 仅剩 736 XLR,排除 |
| 演示形态 | 混合式轨道射击:3D 走廊+世界空间弹幕(全部走 3D 通路,敌弹色键 billboard)+2D HUD;cup3d 硬件版作同分辨率同语义对照 |
| 2D 游戏去留 | MYRIAD 保留为指标演示,3D 是新增模式(菜单切换),不替换 |

核心思路:**3D = 条带模式的推广**,架构属**条带式局部缓冲渲染**(stripe-based local-buffer
rendering;不发「完整 TBDR」的宣称——延迟合成等机制不在本工作点范围)。BAND 条带缓冲即
局部颜色缓冲,旁挂条带 z RAM;每条带内相位化执行(背景装载 → z 清零 → 3D 三角形 → 2D 命令
→ 写回),不与 2D 通路争端口。这是总纲既有映射的落地:F5 硬件分桶=G3 三角 tiler 的 2D 前身
(PB 结构不变,几何层从矩形求交换成 Pineda);条带缓冲↔Mali/Adreno tile memory。
呼应 cup3d 已有软件实测(瓶颈 82% 在光栅):硬件光栅器把 cup3d 送进满帧,即 G3 锚点的嵌赛版。

**静态评审(2026-10-22,外部审阅)主要修订**,已并入各 spec:
三角形 setup 定案由 CPU 完成(硬件梯度归一化需除法,原「无除法器+一拍」矛盾);
R1 数值契约冻结到公式级(采样点/绕序/破平式/guard band 溢出界/舍入表);
S3L 出口前移到视图空间(其屏幕映射整数化、近面默认策略不做正确裁剪,均实证);
BAND/TEX 增设单像素写口与采样口契约(现有口是描述符流,不能直接连线);
整帧生命周期单一化(第 1 页只作参数页,FSM 唯一,TRI_COUNT=0 即绕过);
gfx2d_top 一级页选补进范围;L1/L2 拆 RAST/RAST_TEX 双宏;PB∧RAST 定非法;
synthesis_mode 改显式表;演示判据修正(遮挡分级、30fps 两场节拍、cup3d 同构对照)。
**同日二次修订(用户质询「弹幕怎么还是 2D 的」,成立)**:弹幕全部升为世界空间 billboard
(敌弹色键抠底走 RAST_TEX,L1 纯色方块走 RAST),「2D 阵地」方案废除,2D 层仅剩 HUD;
联动 R1(FLAGS.KEY_EN)/R2(色键跳写)/R3(RAS_KEY)。

## 2 技术选型

| 项目 | 许可证 | 架构与现状 | 借用判定 |

| [SystemVerilog 标量+SIMD 光栅器](https://mummanajagadeesh.github.io/projects/rasterizer/)(Jagadeesh) | 未核 | 结构与本案几乎一致:**屏幕空间参数输入,硬件无 3D 概念**;全定点标量 1px/cycle + SIMD 8px 变体 | 结构参照(CPU 准备参数+硬件增量光栅的先例) |
| [OpenGlory](https://github.com/egorxe/openglory)、[Manticore](https://github.com/thaolt/icculus-manticore)、Columbia/Cornell/[ChaosEngineGPU](https://github.com/Nanousis/ChaosEngineGPU)、[FPGA-Renderer](https://github.com/victoresque/FPGA-Renderer) 等课程/个人项目 | 各异 | 背景:扫描线与 barycentric 两派、SIMD 变体、Zedboard/DE2 先例 | 背景;不深入 |

结论:**光栅核自研**(与 GPU 线「实现自研,外物只作参照与对拍」原则一致),
分工与 RasterIX/Jagadeesh 同构(CPU 准备参数+硬件增量光栅+局部缓冲);
每个设计点都有 2 个以上先例背书,许可红线见 2.5。

| 技术点 | 标准/论文 |

### 2.4 设计点定案(评审后)

| 设计点 | 定案 | 背书/出处 |
| --- | --- | --- |
| setup 归属 | **CPU 完成**(边缘系数、梯度、包围盒,128B 记录下发);硬件只做位置求值+增量扫描。跨条带不重复算梯度,硬件免除法器 | RasterIX 软件侧同法;Jagadeesh 反例(硬件 setup 需另行定义除法,工期不容) |
| 光栅算法 | Pineda 边缘函数,Q12.4、整数采样点、32 位增量、内环零乘法;top-left 破平(E+bias≥0) | Pineda'88;D3D 规则;SpinalVoodoo/ryg |
| Guard band | CPU 屏幕空间 S-H 裁到 x∈[−256,896)、y∈[−256,736),s32 全程不溢出可证 | R1 §2.1 契约 |
| 深度 | 窗口空间线性插值,u16,LESS,z-clear=0xFFFF,条带 z RAM 零 DDR 流量 | Catmull'74;OpenGL 深度变换 |
| UV | 仿射,梯度式,CLAMP;透视校正列 L3 冲刺 | PS1 先例;Heckbert'89 |
| 顶点管线 | CPU:视图空间→近面裁剪→除法→映射→guard band→setup→条带分桶 O(N);S3L 只到视图空间为止 | Sutherland–Hodgman;R1 §2.3 |
| 纹理 | TEX 窗口 16KiB=32×32×32bpp×4 张(64×64 需扩 32KiB,另立预算);FLAGS 位定平涂/无色 | R2 §2.1;R4 §2.2 |
| 弹幕 | 敌弹/自机弹=世界空间 billboard:敌弹色键抠底(FLAGS.KEY_EN+RAS_KEY 寄存器),自机弹纵向小条;L1 纯色方块;**2D 层仅剩 HUD** | 评审遮挡论证的延伸(2026-10-22 用户质询成立);2D 引擎色键语义 |
| 扫描组织 | 1px/cycle 标量(占用 ~18%);SIMD 8px 列 L3+ | Jagadeesh 两变体对照 |
| 取数 | 索引 FIFO+双缓冲参数组两通道;描述符 4KB 任意边界拆分;FD owner 扩三类;**Axi_Mux 保持 X3** | engine_inst 模式+评审修订 |
| 提交 | z+BAND 单像素写为**原子事件**(停等,无部分提交,无三角形间排空);BAND/TEX 新口显式契约 | R2 §2.3/2.4 |
| 生命周期 | 单一:参数页+第 0 页门铃,FSM=LOAD→CLEAR_Z→RAST→2D→FLUSH;TRI_COUNT=0 绕过 | R3 §2.1 |
| 分级 | `GFX_HAS_RAST`(覆盖/深度)+ `GFX_HAS_RAST_TEX`(采样,依赖 RAST+TEX);`PB∧RAST` 非法;synthesis_mode 显式表(PB 或 RAST→speed2) | R3 §2.2 |
