# 绘制前端 F6 条带搬运重叠

状态：**条件启动，未开工**。前置：[F1](../sw/绘制前端F1-成本分解与基线.md)
与 F5 后的关键路径实测；CPU 仍主导时不启动。本批可选，不阻塞 F2~F5 验收。
共同契约见 [总览](../sw/绘制前端总览.md)。

决策依据：engine 第 11 章 D74、D76；启动与采用都由完整关键路径决定。

## 1 要解决什么

单 BAND 在 LOAD/EXEC/FLUSH 三相独占存储。希望用另一套存储隐藏部分搬运时间，
同时保留顺序、像素掩码、同步读延迟、错误与复位排空。191520 周期是旧校准模型
的全帧两相成本，不能直接承诺砍半或把它当条带切换税。

## 2 怎么切分

### 2.1 两缓冲的明确调度

首版只做两套完整 BAND：一套 EXEC，另一套先 FLUSH 前一条带，再 LOAD 下一条带。
预热先 LOAD 0/1，尾部等待所有 FLUSH。每套有状态
`FREE→LOADING→READY→EXECUTING→DIRTY→FLUSHING→FREE`。

```text
bank A: LOAD 0 -> EXEC 0 -> FLUSH 0 -> LOAD 2 -> READY 2 -> EXEC 2 ...
bank B:       LOAD 1 -> READY 1 -> EXEC 1 -> FLUSH 1 -> LOAD 3 ...
```

图只表达依赖，具体能否重叠由 DMA owner 与端口决定。对稳定条带的初步模型为
`max(E, F+L)` 加首尾、争用与仲裁成本，而非自动得到 `max(E,F,L)`。
三阶段同时各占一个完整条带至少需要三份活跃存储；细粒度同 bank 读写复用另作
经过证明的候选，不作为两缓冲的隐藏假设。

### 2.2 资源和带宽

每套 640×16×32 位为 40 KiB，现组织实测 36 RAM；两套较当前约 +36，
4KB 基线约 199 RAM、16KB 候选约 217，另加实例/PB 前端与新增状态/FIFO。
三套分别约 235/253 加前端，主线不默认采用。所有值为预算，不代替综合。

全帧 LOAD+FLUSH 仍为 2×640×480×4=2457600 B；128 位路径为 153600 数据拍。
实际 DDR 与 AXI 争用可能不能同时读写，重叠只隐藏可并行部分，不降低这些字节。
STRIP_H=32 的行数、字节也不变，只可能减少条带级控制与跨带片段。

### 2.3 接口、仲裁和错误

I1/几何提交增加 bank_id；每个本地描述符、像素边带、同步 RAM 读与状态都携带
bank/strip/帧上下文直到完成，不能随全局当前 bank 变化。I5 row_free 仍只代表
像素行缓冲，新增 BAND owner 不能借它代替。

取消现 `b_xfer` 的全局阶段互斥前，给 command/instance/PB/源像素/背景读和
像素/FLUSH/PB 写分别定义 owner，读写核心一次只接有明确归属的请求。
仲裁保持现扫描通路的防饿死约束；增加逐 owner 有界等待的压力验证。

状态必须等本 bank 本地读写、状态 FIFO、DMA 尾拍/B 响应全部完成后才 FREE。
LOAD 错禁止 READY，EXEC 错禁止正常交换，FLUSH 错不得误释放或呈现。
软复位先停新任务，排空所有 bank 和 owner；LIST_DONE 在最后 bank 完成 FLUSH
且所有预取/状态排空之后，PERF 仅计一次真实事务。

### 2.4 文件与阶段

先在 `sim/engine/frontend` 建独立调度模型与 owner 监视器；随后封装单 BAND
为可实例化的数据面，增加 `engine_band_sched.v`，再接 mover/geom/pix/cmd。
保持旧单缓冲运行时或编译对照，首版不同时调整 H、cache 容量、像素格式或压缩。
新增 `CAPS.BAND_DUAL=bit14`，启用控制由独立模式位/参数生成，不挤占旧 CTRL。
首版采用 `CTRL.BAND_DUAL=bit5`，要求 BAND=1，能力不支持则门铃前拒绝。

诊断阶段计数另放 RO 窗口 0x180/184/188/18C：LOAD、EXEC、FLUSH、OVERLAP
各为累积 32 位周期数，CNT_CLR 在空闲时清零；同时处于多个相位时相应分项都加一，
OVERLAP 在至少两个有效相位同拍工作时加一。它们不与 0x140 起 PB 参数或旧 PERF
数组重叠，也不能相加后冒充总忙周期。软件以同一完成区间取增量，回卷用无符号减法。

## 3 判据

- 每 bank 的像素/掩码/owner 与独立模型逐拍一致；跨带、空带、读写同址、末拍
  反压、随机响应延迟、短/长响应、复位/超时覆盖，整体像素对直通一致。
- owner 丢失、早 FREE、错 bank、末写未回即 DONE、取消漏一 bank 至少五个
  变异见红；旧单缓冲 v2/PB/直通回归保持。
- 单独与整机综合记录 +RAM/XLR、所有时钟域 slack；实际预算不足不采用。
- 在同输入、同缓存、同 H 下记录 L/E/F、重叠区间、仲裁等待、总关键路径与
  扫描水位。若 CPU 仍主导或总帧关键路径不降，不能宣称 N_max 获益。
- 真实整机双型 N_max、回放与扫描门槛沿总览；不存在“固定税减半”的独立验收替代。
