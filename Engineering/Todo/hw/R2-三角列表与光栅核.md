# R2-三角列表与光栅核(engine_rlst / engine_rast)

状态:**未开工**(spec 成稿 2026-10-22;2026-10-22 静态评审后修订:ABI 补到字节级,
setup 移交 CPU,取数与像素提交微架构定案,BAND/TEX 写成显式端口契约)。
阻塞于 R1 契约冻结。总览见 [三维光栅总览.md](三维光栅总览.md)。

## 1 要解决什么

给引擎增加三角形光栅执行硬件:CPU 交 **setup 完毕**的三角形(R1 的 96B 记录,含边缘系数、
梯度、包围盒),硬件做位置求值、增量扫描、z 测试、TEX 采样与顶点色调制,把像素写进
BAND 条带缓冲。本条目只做单元级(RTL+单元仿真),集成/预设/生命周期归 R3。
分级:**GFX_HAS_RAST**=覆盖+深度+BAND 接入(L1 平涂也在内);
**GFX_HAS_RAST_TEX**=TEX 采样(L2),依赖 RAST 与 TEX;旧 `GFX_HAS_TEX` 两种构型都保留
(L1 不许以关闭 2D 纹理能力为代价)。

## 2 怎么切分

### 2.1 列表 ABI(R1 §2.1 字节表为唯一规格源,此处只定组织)

- 主表:96B setup 记录连续存放,基址 32B 对齐;记录可跨 4KB 页。
- 条带子表:按 strip 顺序连续排放,`[u16 count][u16 rsvd] + count × u16 主表索引`;
  count=0 的条带整体跳过。索引语义:主表记录号,< TRI_COUNT;越界、保留位非 0 归首错
  (错误码 BAD_INDEX,ERROR_STAGE=7 光栅;定位复用 ERROR_INDEX/TAG 纪律)。
- TRI_COUNT=0 是合法空帧(R3 的 FSM 据此跳过 RAST 相位,零开销推进)。

### 2.2 engine_rlst(取数)

评审证实不能「仿 engine_inst」一句话带过(一个缓存既装索引又装随机 gather 的记录会互相
覆盖),微架构定案:

- **索引通道**:子表经独立 64 深 u16 FIFO(小 RAM/SRL)顺序流入,与记录通道隔离。
- **记录通道**:独立描述符(按索引生成地址),数据进 **双缓冲参数寄存器组**
  (2×96B=48 词,约 1.5k FF);三角形 N 被光栅核消费时预取 N+1。
- 描述符拆分:**4KB 任意字节边界**可拆(96B 记录允许跨页,流式重组;
  命令引擎那条「记录边界拆分」规则不适用于本通道)。单描述符 ≤64 拍(128 位),与 inst 同款。
- 搬运层 FD owner 编码扩到「命令/实例/光栅表」三选一;光栅表读计入真实 DDR 读(PERF 口径同命令取数)。
- 索引 FIFO 空、记录未就绪时光栅核停等;cancel/错误丢弃在途并回空闲(排空纪律复用)。

### 2.3 engine_rast(光栅核)

流水:三角形装载(参数组切换)→ 位置求值 → 逐像素(1px/cycle)→ 原子提交。

1. **位置求值**(每三角形一次,6 个 DSP 乘法):E_k(bbox 起点)=C0 + A_px·i0 + B_px·j0;
   z/u/v 累加器同点求值;z/u/v 提交值 = 累加器右移舍入(R1 §2.1 式)。
2. **扫描**:bbox∩条带∩帧内逐行;bias 由 (dx,dy) 符号推导(top ⟺ dy==0&&dx>0,
   left ⟺ dy<0,判内 E+bias≥0);内环只有加法。
3. **z 测试**:z RAM 640×STRIP_H×16b(独立双口:同步读+同步写),复位值 0xFFFF,
   换带清零(CLEAR_Z 相位,与 LOAD 并行,R3)。
4. **采样与调制**(`GFX_HAS_RAST_TEX`):TEX 新采样口(2.4);FLAGS.TEX_EN=0 或 VCOLOR_EN=0
   按位退化;调制按 3.5 节 V 顺序 ÷255。FLAGS.KEY_EN=1 时,采样 texel==RAS_KEY
   (3D 页寄存器)的像素**整像素跳过(色与 z 都不写)**,比较在调制前——色键抠底的
   billboard 弹幕靠它,语义与 2D 引擎色键一致(跳过=该像素完全不变)。
5. **原子提交**:z 测试通过的同拍,发 z 写 + BAND 单像素写;BAND `ready=0` 时整像素停等,
   **不存在部分提交**。跨像素流水正确性论证写进码档:像素 N 写在 t 拍、像素 N+1 的 z 读在
   t+1 拍,BRAM 写先读后可见;同像素不重读。**三角形间不加排空拍**
   (事件原子性已排除旁路风险;评审建议的每三角形排空作为备选路径,若仿真抓到旁路缺口才启用,
   换固定开销)。取消/错误:丢弃 staged 状态,记首错,回空闲。

资源预算(估算):光栅核 3~5k XLR/setup 移交 CPU 后比原估降,DSP 8~14;
rlst ~1k XLR + 索引 FIFO 2 RAM;z RAM 16 块;参数组 ~1.5k FF。
`core_clk` 100MHz,1px/cycle,像素段 ≤4 拍浅流水。

### 2.4 BAND / TEX 端口契约(评审证实现有口不能直接连线,新增,不改既有口)

- **engine_band 新光栅写口**:`ras_wr_pix(local 线性像素号 [10:0], data[31:0], valid)` +
  `ready`;RAM 写口在 RAST 相位内独占(相位互斥由 R3 的 FSM 保证,本模块不仲裁);
  与 LOAD/FLUSH 的时序边界沿用「下一条带不能提早覆盖」契约。
- **engine_tex 新采样口**:`samp_req(addr[15:0],16b 字窗口偏移)` → 固定延迟
  TEX_READ_LATENCY 拍返回 `samp_data[31:0]`;单笔在途,bank 按 addr[1:0] 选
  (每 texel 一词);与 APB 装载口、mover 描述符口互斥(RAST 相内无装载,FSM 保证)。
- 两个新口的关闭态(`GFX_HAS_RAST` 无)整块不进编译输入,第 7 章关闭态契约表相应增行。

### 2.5 单元仿真(sim/engine/rast、sim/engine/rlst)

- 沿用 sim/engine harness 体例(AXI 从机模型带随机反压);期望值=R1 导出的向量(交换格式)。
- 用例组:R1 两层手算向量 + 定种子随机记录流 + 空子表 + 索引越界首错 + 跨 4KB 记录
  (构造 96B 记录横跨页界)+ `GFX_HAS_RAST_TEX` 关闭平涂构型 + z 相等 LESS 不写。
- 注错(每类只命中自己的用例):A_px 漏 ×16、bias 推导反、z 比较方向反、
  提交舍入常数错、跨页重组丢尾拍、索引 FIFO 溢出未停等、色键比较恒不命中
  (billboard 抠底失败,出现方块底色)。

## 3 判据

1. 随机记录流(R1 同种子)RTL vs rast_ref 对拍 fail 0;RAST_TEX 开/关两构型都过。
2. 六类注错各自见红且不影响无关用例。
3. 跨 4KB 记录用例单列并通过;空子表条带零开销推进在波形上可指认。
4. iverilog 零新增告警;排版检查过;按验证流程选检查(不默认全仓回归)。
5. BAND/TEX 新口以契约表形式进 engine-manual(端口、相位互斥、延迟、关闭态),
   与 2.4 逐条一致。
