- 收录未开工的 spec、进行中的开发日志，以及已实现但未验收的事项。
- 已完成项先补齐 TechReports 的开发记录（前期研究与实验取样的过程、数据和解释写在那里），
  再同步受影响目录的 README，然后把状态改为「待验收」。**验收之后**才删除本目录的文件。
- 跨会话的停点与续接状态记在本条目的开发日志，来源与借鉴边界直接写 TechReports 正文；
  不在代码或证据目录另立 STAGE、notes 之类的阶段文件。
- 部分完成按工作点写清剩余验收；「代码已有」「仿真通过」「上板通过」分开记录。
- 已明确不做、延期或被其它任务覆盖的方案，不当成已实施。
- 正文保留开发过程时，以文件顶部最新状态为准。
