1. 会进网表的改动攒起来一次做、一次编译。每次改动都会扰动布局，
   `core_clk` 的 hold 余量只有 0.026 ns，每次都要重新核对 setup 与 hold。

   两边对不上时 Interface Designer 只在 Missing Interface Pins 里列出，不报错。
